# Configuration Files

This folder contains all JSON configuration files for the DynamoDB MCP project.

## MCP Configuration Files

### Claude Desktop Configurations

- **`claude_desktop_config_sh.json`** - MCP configuration for Claude Desktop (bash/Linux)
  - Generated automatically by `apply.sh` or `scripts-powershell/apply.ps1`
  - Contains MCP server configuration with bash proxy
  - Copy this to your Claude Desktop config file after deployment

### Alternative MCP Configurations

- **`mcp-config-powershell.json`** - MCP configuration template for PowerShell proxy
  - Uses `powershell.exe` command
  - For Windows systems
  - Contains environment variables for AWS credentials and API endpoint

- **`mcp-config-fixed.json`** - Fixed MCP configuration for bash proxy
  - Uses bash command with Unix-style paths
  - For Linux/Mac or WSL systems

## Test Output Files

- **`test-output.json`** - Sample test output from DynamoDB operations
  - Used for testing and validation
  - Shows expected response format

## Configuration Structure

All MCP configuration files follow this structure:

```json
{
  "mcpServers": {
    "dynamodb": {
      "command": "bash|powershell.exe",
      "args": ["path/to/proxy.sh|proxy.ps1"],
      "env": {
        "MCP_ACCESS_KEY_ID": "your-access-key",
        "MCP_SECRET_ACCESS_KEY": "your-secret-key",
        "MCP_API_ENDPOINT": "https://your-api-endpoint.amazonaws.com/",
        "MCP_REGION": "us-east-1"
      }
    }
  }
}
```

## Usage

### After Deployment

1. **Locate your Claude Desktop config file:**
   - **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`
   - **Mac**: `~/Library/Application Support/Claude/claude_desktop_config.json`
   - **Linux**: `~/.config/Claude/claude_desktop_config.json`

2. **Copy the generated configuration:**
   ```bash
   # View the generated config
   cat configs/claude_desktop_config_sh.json
   ```

3. **Add to Claude Desktop config:**
   - Open your Claude Desktop config file
   - Merge the contents of `claude_desktop_config_sh.json`
   - Save and restart Claude Desktop

### Manual Configuration

If you need to manually configure the MCP server:

1. Choose the appropriate template:
   - **Windows**: Use `mcp-config-powershell.json`
   - **Linux/Mac**: Use `mcp-config-fixed.json`

2. Update the environment variables:
   - Replace `MCP_ACCESS_KEY_ID` with your IAM user access key
   - Replace `MCP_SECRET_ACCESS_KEY` with your IAM user secret key
   - Replace `MCP_API_ENDPOINT` with your API Gateway endpoint
   - Set `MCP_REGION` to your AWS region

3. Update the proxy path:
   - Set the correct absolute path to `proxy.sh` or `proxy.ps1`

## Security Notes

⚠️ **Important**: These configuration files contain AWS credentials. 

- **Never commit these files to version control**
- Keep them secure and private
- Rotate credentials regularly
- Use least-privilege IAM permissions

## Generated Files

The following files are automatically generated during deployment:

- `claude_desktop_config_sh.json` - Generated by deployment scripts
  - Contains credentials from AWS Secrets Manager
  - Automatically configured with correct API endpoint
  - Ready to use after deployment

## Troubleshooting

### Configuration Not Working

1. **Check proxy path**: Ensure the path to `proxy.sh` or `proxy.ps1` is absolute and correct
2. **Verify credentials**: Ensure AWS credentials are valid and have proper permissions
3. **Check API endpoint**: Verify the API Gateway endpoint is accessible
4. **Test proxy**: Run the proxy script manually to check for errors

### Credential Issues

If you see authentication errors:
```bash
# Verify credentials work
aws sts get-caller-identity

# Check API Gateway endpoint
curl -X GET "https://your-api-endpoint.amazonaws.com/tools"
```

- No trailing commas
- UTF-8 encoding
